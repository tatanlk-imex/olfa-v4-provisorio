Prueba el bot de OLFA Chile

Conversa como si fueras un cliente. Este es el mismo bot que irá a WhatsApp. Tus comentarios ayudan a entrenarlo.

Cómo probar

  1. Escribe o toca los botones del celular, como en WhatsApp.
  2. Haz preguntas reales: cuchillos para una bodega, hojas de repuesto, garantía, despacho, visitas, normas, un reclamo.
  3. Toca 👍 o 👎 bajo cada respuesta. Si es 👎, cuéntanos cómo debió responder.
  4. Al terminar, pulsa Enviar mis comentarios.
