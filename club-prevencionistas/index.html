Club de prevencionistas

Club OLFA Prevención

Tu empresa se inscribe a través de un prevencionista y recibe implementos de seguridad de regalo. El prevencionista recibe un kit para demostrar en terreno qué herramienta conviene a cada tarea.

🏢

Para la empresa

Obsequio de accesorios o implementos de seguridad OLFA para su equipo.

🧰

Para el prevencionista

Un kit de herramientas para demostrar y poner en práctica qué implementos de seguridad son los más idóneos para cada empresa, según las funciones que desarrolla.

🤝

Cómo funciona

La empresa no se inscribe sola: lo hace a través de un prevencionista, o el prevencionista inscribe a una o más compañías.

Inscríbete

Completa el formulario. Se abre tu programa de correo con la inscripción lista y solo debes presionar Enviar. Un ejecutivo de Imex te contacta para coordinar la entrega.

¿Cómo te inscribes? *

Prevencionista

Compañía a inscribir

Cómo es el proceso

  1. Inscripción: la compañía, o el prevencionista a nombre de una o más compañías, completa el formulario con los datos del prevencionista.
  2. Contacto: un ejecutivo de Imex valida los datos y coordina contigo.
  3. Entrega: la empresa recibe sus accesorios o implementos de seguridad y el prevencionista su kit de demostración.
  4. Terreno: el prevencionista prueba con el equipo qué modelo conviene a cada tarea.
Los implementos que se entregan y las condiciones de participación se informan al inscribirte. Mira también la guía para prevencionistas y la agenda de visitas.
